Conhecendo Imagens

Entendendo o elemento img

  • src: Indica onde está a imagem. O src significa souce/fonte = origem.
  • alt: O alt serve para descrever a imagem para quem não consegue vê-la, além de ajudar na acessibilidade. O alt significa altenative/alternativo

Sobre os diferentes tipos de imagem

Abaixo, temos uma lista dos diferentes tipos de imagens e quando usar:

  • JPEG/JPG: Bom para fotos de produtos, paisagens, e fotos, pois, possui um arquivo relativamente pequeno. Não suporta transparência e caso seja comprimida várias vezes, pode perder qualidade.
  • PNG : Execelente escolha quando queremos transparência e preservar bastante a qualidade. Geralmente usamos para logos, imagens com transparência, gráficos simples.
  • WebP: Formato moderno desenvolvido para a web. Muito menor que o JPEG e PNG, mantém a qualidade da imagem pois suporta comprenssão sem perda. usamos para qualquer imagem comum na web.
  • AVIF: Assim como o formato WEBP, é um formato moderno e também é capaz de produzir arquivos bastantes pequenos/leves mantendo uma ótima qualidade. Geralmente usamos esse formato, quando queremos priorizar performance.
  • SVG: O SVG é um elemento vetorial, excelente para logos, ícones, ilustrações, formas geométricas e gráficos. A vantagem desse elemento, é que ele pode ser ampliado sem a mesma perda de nitidez de uma imagem baseada em PIXELS.
